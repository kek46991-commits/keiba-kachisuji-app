# 買い目表示復旧・画面確認メモ

- 対象：園田 7R（2026-08-14、保存済み見送り予想）

保存済みデータは `totalBets: 0`、`trifecta: "見送り"` であることをDBで確認した。実装後に同レースの画面内容を確認し、3連単9点・3連複3点・合計12点の**参考フォーメーション**と、購入推奨・精算・実績集計の対象外である注意文が表示されることを確認した。

自動スクリーンショットは非同期データ取得完了前のローディング状態を捕捉したが、ページ本文の取得では保存済みカードの表示内容を確認できた。型検査および99件の回帰テストは通過済みであり、保存済みの見送りを購入非推奨の参考フォーメーションへ再構成するユニットテストも追加済みである。

最終確認では、園田7Rの保存済み予想に「参考フォーメーション: 1着2 / 2着7,3,8 / 3着7,3,8,9」、3連複3点、参考組合せ12点、および購入推奨なしの説明が1回だけ表示された。穴狙いの既存買い目は通常の購入対象として従来どおり別カードに保持されている。
