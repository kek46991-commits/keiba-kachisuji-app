# 独自テスト用：予想生成CSV形式

この形式は、**予想ロジックの動作検証だけ**を目的とする。実在する競馬場名、レース名、馬名、騎手名、オッズ、画面キャプチャ由来の数値は入力しない。

## CSVヘッダー

```csv
race_id,race_name,horse_number,horse_name,jockey,ability_score,track_score,paddock_score
```

## 入力ルール

| 列 | 必須 | 形式 | ルール |
|---|---:|---|---|
| `race_id` | はい | 文字列 | `test-20260822-a` のような独自ID |
| `race_name` | はい | 文字列 | `テストレースA` のような非実在名 |
| `horse_number` | はい | 整数 | 同一レース内で重複しない1以上の値 |
| `horse_name` | はい | 文字列 | `テストホース01` のような非実在名 |
| `jockey` | いいえ | 文字列 | `テスト騎手A` のような非実在名 |
| `ability_score` | いいえ | 0〜100の数値 | 独自に作成した検証値のみ |
| `track_score` | いいえ | 0〜100の数値 | 独自に作成した検証値のみ |
| `paddock_score` | いいえ | 0〜100の数値 | 独自に作成した検証値のみ |

## 禁止する入力

実在の競馬場、開催日、レース名、馬名、騎手名、公式・民間のオッズ、人気順、画像から転記した数値、個人契約サービスから得た値は含めない。

## テストで確認すること

入力された行数に応じて、スコア順、穴馬軸、表示できる券種を正しく分岐することを確認する。3頭未満の場合は不可能な3連系を作成せず、欠損したスコア要素は未算出として扱う。
