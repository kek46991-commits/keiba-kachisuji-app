# 能力差連動の1着候補分散フォーメーション検証

## 実装ルール

能力スコア1位と2位の差が4.0点以下の場合、スコア順買い目の1着候補を上位2頭へ分散する。2着候補は上位3頭、3着候補は上位5頭を採用し、重複馬番を除いた3連単12点・3連複4点、合計16点を上限とする。スコア差が4.0点を超える場合、従来どおり1位を1着軸として3連単9点・3連複3点を構成する。

穴馬軸買い目は、穴軸の爆発力を保つため1着軸を無条件に増やさず、従来どおり穴推奨馬を軸にする。分散はスコア順買い目だけに適用する。

## 自動検証

型検査とVitest全110件は通過した。能力差3.0点で1着候補が2頭へ分散し、3連単12点・3連複4点になること、候補3頭では低根拠の馬を補充せず分散カバー5点にとどめること、能力差が十分にある場合は1着固定を維持することをテストした。

## 画面検証状況

中央・地方の対象URLを同時にキャプチャした初回時点では、非同期のレース情報・出走馬データを読込中だったため、買い目カードはまだ表示されなかった。読み込み完了後に再予想を実行し、分散条件に該当する実データでカード表記を再確認する。

中京7Rで読み込み完了後のカードを確認した。能力1位13番（62点）と2位7番（60点）の差が2点のため、1着候補は13・7へ分散され、3連単12点、3連複4点、合計16点として表示された。穴馬軸買い目は13番を1着軸とする従来の16点＋3点を維持している。

公式組合せオッズ未取得の警告内では、全券種の総投資と、実際に公式オッズで照合できた対象券種の投資を分けて表示する。これにより、カード上部の合計16点・想定投資1,600円と、公式照合対象の投資額を混同しない。

最終確認では、スコア順買い目に「全券種の総投資 1,600円（3連複を含む）」と「公式照合対象の投資 1,200円」を別行で表示できた。公式組合せオッズが存在しない状況でも、全体の想定投資額と公式照合に使える範囲が明確に区別される。
