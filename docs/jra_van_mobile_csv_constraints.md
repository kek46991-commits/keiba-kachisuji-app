# JRA-VANスマホ運用とCSV取込の確認記録

確認日: 2026-08-13

JRA-VANの公式製品ページでは、**JRA-VAN データラボはWindowsパソコン向けサービスであり、スマートフォンでは利用できない**と明記されている。データラボ契約者はJRA-VANスマホアプリを利用できるが、JV-Link／利用キーによるデータ取得はPC向けの利用手順である。

同社の公式ヘルプでは、CSV形式のデータが必要な場合、対応する競馬ソフトの**テキストエクスポート機能**でCSV出力する方法が案内されている。したがって、PCを利用しない前提では、スマホアプリ内の閲覧可能な情報とWebアプリへの公式CSV取込を混同せず、スマホで取得・保存できる公式ファイルがある場合だけ本アプリへ取り込む。

本プロジェクトは、未許諾のサイトへの自動アクセスを行わない。公式CSVがスマホからアップロードされた後は、結果・払戻・予想精算・成績更新を自動処理する。

## サーバー向け連携の契約上の制約（追記）

JRA-VANスタッフの2026年7月の公式案内では、Data Lab.（JV-Link）のデータをアプリ・サービス経由でエンドユーザーへ提供する行為は再配布・二次利用にあたり、通常のData Lab.契約では行えないとされている。この形態での利用には、JRAが提供する商業利用契約「JRADB」が必要であり、対象は法人契約のみで、個人契約は原則受け付けないと案内されている。

また、JV-LinkはActiveX COMコントロールで、対応競馬ソフトからローカルPCへデータを取得する仕組みである。したがって、スマホのみのWebアプリからData Lab.の利用キーを使って直接サーバー取得することは、この公式設計に合致しない。

本アプリでJRAデータを自動取得してエンドユーザー向け表示へ利用するには、法人契約済みのJRADB等、用途・配信先が明示的に許諾されたサーバー向け公式データ配信と接続仕様が必要である。
