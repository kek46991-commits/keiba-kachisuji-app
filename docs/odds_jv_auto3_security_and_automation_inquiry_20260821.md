# Odds JV Auto3：安全性および個人PC内自動取得に関する問い合わせ文面

**宛先候補**：OJVAutoPro@maitonclub.com  
**件名**：Odds JV Auto3 3.2.0のWindows 11導入・署名確認および個人PC内定時取得について

まいとん倶楽部 ご担当者様

お世話になっております。JRA-VAN Data Lab.を個人契約で利用しており、JRA-VAN公式のData Lab.対応ソフト紹介ページから、Odds JV Auto3 3.2.0のインストーラーをダウンロードしました。

Windows 11環境でインストーラーを起動したところ、Microsoft Defender SmartScreenにより「発行元：不明な発行元」と表示されました。JRA-VAN公式サイトに掲載された配布ファイルであることは確認していますが、安全に導入するため、以下についてご教示いただけますでしょうか。

1. 現在配布中のインストーラー `OJAINSTV3200.EXE` は、Odds JV Auto3 3.2.0の正規ファイルでしょうか。
2. 当該ファイルに電子署名がない場合、正規性を確認するためのSHA-256ハッシュ値、または同等の確認方法をご提供いただけますでしょうか。
3. Windows 11 64bit環境での導入にあたり、Microsoft Defender SmartScreenの警告について、公式に推奨される確認・対処手順はありますでしょうか。
4. Data Lab.の利用規約を遵守し、取得したデータを本人の個人PC内だけで保存・分析し、第三者への公開・配布・Webサイトへの連携を一切行わない前提で、Odds JV Auto3の指定時刻自動取込およびPC起動後の自動運転を利用して差し支えないでしょうか。
5. 上記の個人利用範囲において、推奨する設定方法、注意事項、または利用頻度に関する制約があればご教示ください。

なお、利用キー、JRA-VAN ID、パスワードその他の認証情報はメール本文・添付ファイルともに共有いたしません。

お忙しいところ恐縮ですが、ご確認のほどよろしくお願いいたします。
