# PCからスマホへ公式CSVを受け渡す最小運用

## 目的

PCで契約済みJRAデータサービスを利用して公式データを確認・CSV出力し、スマホの「競馬でGO！」で数タップのうちに取込、結果精算、予想履歴の更新まで進める。未許諾の外部サイトからの取得や、Data Lab.の利用範囲を超えるサーバー自動配信は行わない。

## 推奨フロー

| 段階 | 操作 | 自動化される処理 |
|---|---|---|
| 1. PC | JRA-VAN対応ソフトから、対象開催日の出馬表CSVと払戻CSVを指定フォルダへ出力する | PC側で公式データを取得・CSV化する |
| 2. 同期 | 指定フォルダをGoogle Drive、OneDrive、iCloud Driveなど本人のクラウドフォルダと同期する | PCからスマホへファイルが届く |
| 3. スマホ | 本アプリの「公式CSVデータ取り込み」を開き、「クラウドストレージを選択」から2ファイルを選ぶ | ファイル検証、重複検知、レース照合を実行する |
| 4. アプリ | 取込を確定する | 公式結果・払戻の保存、過去AI予想の精算、的中率・回収率更新、当日成績通知を自動実行する |

## PC側の整理方法

同期フォルダを1つだけ用意し、ファイル名を日付と用途で統一する。例えば、`JRA_20260815_entries.csv` と `JRA_20260815_payouts.csv` のように保存する。同一日付の再出力では末尾に時刻を付ける。スマホ側では最新ファイルを選択するだけでよく、古いファイルを間違えるリスクを下げられる。

PCでCSVを出力できるJRA-VAN対応ソフトを利用する。JRA-VANの公式ヘルプは、CSVが必要な場合には対応ソフトのテキストエクスポート機能を利用するよう案内している。[1]

## スマホ側の最小操作

スマホでは、クラウドストレージのファイル選択画面から「出馬表CSV」と「払戻CSV」を順に選択する。アプリは開催日・競馬場・レース番号を検証し、対象レース、結果確定数、精算数、保留数を表示する。確定を押した後は、的中件数、投資額、回収額、当日収支の通知を表示する。

## 段階的な改善候補

第一段階では、OS標準のファイル選択画面を使う二ファイル取込を維持する。これは追加契約が不要で、スマホ側の操作は数タップで完結する。

第二段階では、本人のクラウドストレージ連携を追加し、同期フォルダに届いたCSVを一覧から選択できるようにする。この段階では、データ利用契約がクラウド保管・本アプリへの取込を許容するかを契約内容で確認する。

第三段階では、法人化後にJRADB等のサーバー向け公式データ配信契約を結び、公式の接続仕様に従って結果・オッズを自動取得する。JRA-VANの公式案内では、Data Lab.の通常契約によるエンドユーザー向けデータ提供は再配布にあたり、商用のサーバー向け利用にはJRADBが必要と説明されている。[2]
