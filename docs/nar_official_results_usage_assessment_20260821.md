# NAR公式結果データの利用条件確認

確認日: 2026-08-21  
対象: 地方競馬情報サイトのレース結果・払戻を、戦略別予想の精算へ利用する可否

## 確認した事実

地方競馬情報サイトは、開催日程・出馬表・レース結果・払戻を公式情報として掲載している。FAQでは、単勝オッズおよび賭式別オッズを掲載し、オッズは発売開始から競走実施日の4日後まで閲覧できるとしている。また、1998年以降の競走成績を「月別開催日程」から閲覧できるとしている。

一方で、利用規約は掲載情報の権利が原則として主催者等に帰属し、事前許諾のない転載・複製を禁止している。FAQも、出走表や競走成績等のレース情報の商用利用および改変しての転載を禁止し、レース情報提供の契約を希望する法人・団体は問い合わせフォームから相談するよう案内している。

## 実装判断

NAR公式ページのHTMLや閲覧用情報を、自動取得してWebアプリのDBへ保存・精算へ流用する実装は行わない。過去日付で `upcoming` のまま残っているNARレースを `results_confirmed` に変更するには、許諾済みのCSV、API、または契約データを使い、着順上位3頭と払戻を両方取り込む必要がある。

結果データが正規に取り込まれるまでは、戦略別買い目73件ずつを回収率・的中率の学習母集団に含めない。

## 公式問い合わせ窓口

NAR公式FAQは、レース情報提供に関する契約を希望する法人・団体は「ご意見・ご要望」メールフォームから相談するよう案内している。フォームは記入者名、メールアドレス、件名（当サイトについて／地方競馬全般について／その他）、本文を入力して確認画面へ進む構成である。個別回答を保証する窓口ではない旨が明示されている。

問い合わせ先: https://l-horse.net/anquete/goikengoyoubou

## 代替窓口の確認結果

2026-08-21にNAR公式FAQとテレホンサービス案内を再確認した。FAQはレース情報提供契約の相談先として上記フォームのみを指定しており、公開された代替の契約相談メールアドレスは確認できなかった。テレホンサービスは各競馬場のレース結果・払戻情報を音声で案内する用途であり、データ利用許諾や契約相談の窓口ではない。

フォームで送信できない場合は、ブラウザを変更・更新して同フォームを利用するか、NARへ郵送等の正式な連絡手段を個別に確認する必要がある。未確認のメールアドレスへ問い合わせを送ることはしない。

## 公開ページと正規データ提供方法の確認

2026-08-21に地方競馬情報サイトのデータベース検索ページと地方競馬全国協会の調達情報を確認した。公開ページは閲覧用の検索・表示機能であり、結果精算用途へ利用できる公開API、CSVダウンロード、または契約データの認証入口は確認できなかった。公開ページのHTMLを取得して代用することは、FAQに示されたレース情報の二次利用条件と整合しないため実施しない。

よって、結果取込を開始する前に、NARから許可されたCSV配布URL、API仕様書、または契約データ提供元・認証手段を特定する必要がある。`https://www.keiba.go.jp/` は公式の閲覧サイトとして扱い、取込エンドポイントとしては扱わない。

## ケイバGO!アプリの確認結果

ケイバGO!はNAR公式のスマートフォン向け閲覧アプリで、出馬表、レース結果、払戻金をリアルタイムに表示する。公式案内・利用規約にはCSV出力、外部API、データ共有の機能は記載されていない。利用規約は、表示情報を私的利用の範囲を超えて転用・複製すること、二次利用すること、アプリの仕組みを解析することを禁止している。

このため、ケイバGO!からの画面取得、通信解析、外部サーバーへの取込を結果精算の方法として採用しない。結果精算には、別途許可されたCSV・API・契約データを使う必要がある。

## フォーム送信不成立時の正規連絡手段

NARの公式協会案内には、地方競馬全国協会の代表電話および郵送先として以下が掲載されている。公式FAQが指定するデータ提供契約相談フォームが送信できない場合は、代表窓口へ「レース情報提供契約・CSV/API利用の相談先」を電話で確認し、案内された部署・方法だけを利用する。

NARの公式案内は、全国の競走成績、売上等を一括管理する情報システム（IRIS）の開発・運用、および出走表、オッズ、競走結果等のリアルタイム掲載を業務として記載している。これはデータ提供契約の公開APIを意味するものではないため、提供方法・利用条件は必ずNARへの個別確認を要する。
