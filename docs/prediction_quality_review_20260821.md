# 予想精度・買い目品質レビュー

作成日: 2026-08-21  
対象: 保存済み予想、確定結果、戦略別買い目の監査可能性

## 結論

保存済みの確定予想338件は、旧形式の買い目が中心で、総点数・戦略別の実券面を監査できる現行形式の実測データがありません。このため、過去の見かけ上の的中率・回収率を根拠に、能力スコアの重みや穴馬条件を機械的に最適化することは行いません。

今回の変更は、的中や収益を保証するための調整ではなく、低根拠の買い目を通常推奨として出さないための品質ゲートです。今後は、スコア順買い目と穴馬軸買い目を戦略別に保存し、確定払戻と照合できるレースだけを評価母集団にします。

## 観測された状況

| 指標 | 確認値 | 解釈 |
|---|---:|---|
| 確定済み予想 | 338件 | 過去結果は存在する |
| 予想上位3頭と実際の3着内の平均重なり | 0.74頭 | 上位評価の再現性は十分とはいえない |
| 上位3頭と3着内の重なりが0頭 | 134件 | 買い目を広げる前に、根拠の品質確認が必要 |
| ◎が3着内 | 81件（24.0%） | 単軸固定を常用する根拠としては弱い |
| 監査可能な現行形式の買い目 | 0件 | 旧形式の投資額・払戻額は新方式の比較に使用しない |

## 実装した改善

### 1. 能力評価と市場評価を分離

能力スコアは騎手・枠・血統・馬体重などの非市場要因だけで構成し、予想オッズは市場で成立した公式オッズとして扱いません。公式オッズが未取得の状態では、EV・トリガミ・市場急変を未算出として表示します。

### 2. 独立根拠ゲート

予想オッズモードで、上位候補に騎手・枠・血統・馬体重の独立した能力根拠が不足する場合、スコア順の券面は購入推奨ではなく参考フォーメーションへ切り替えます。点数を埋めるための候補追加は行いません。

### 3. 2系統の買い目を維持

スコア順買い目は能力差が4点以下の場合に1着候補を2頭へ分散します。穴馬軸買い目は、穴候補を軸にしつつ、能力上位馬を2・3着候補から外さないフォーメーションを維持します。

### 4. 外部HTML取得の除外

中央予想処理では、第三者サイトのHTMLを出馬表・オッズの補完元として使いません。予想に使用するのは、DBへ取り込まれた公式または許諾済みデータに限定します。出馬表が未取込の場合は、予想を停止して正規データの取込を促します。

## 今後の評価ルール

1. 戦略別買い目（score / longshot）を予想時点で保存する。
2. 公式払戻と照合できた確定レースだけを実績に採用する。
3. 市場オッズが未取得のレースは、EV・トリガミ・回収率の検証対象から除外する。
4. 一定数の現行形式レースが蓄積されるまで、スコア重みの大幅変更は行わない。

> 競馬には不確実性があり、予想・買い目・回収率は利益や的中を保証するものではありません。
