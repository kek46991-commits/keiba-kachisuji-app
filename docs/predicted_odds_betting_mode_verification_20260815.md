# 予想オッズによる通常買い目モードの検証記録

## 実装範囲

公式オッズの公開連携が未契約の期間は、能力スコアを同一レース内で正規化した推定勝率の逆数を「予想オッズ」として小数第1位まで表示する。これは市場で成立した公式オッズではないため、EV、市場シグナル、組合せオッズによるトリガミ判定には使用しない。

中央・地方の新規予想では、公式オッズ・EVが未取得でも能力スコア順位から通常のスコア順フォーメーションを生成する。候補5頭では3連単9点と3連複3点、合計12点を上限とする。低根拠の馬を追加して点数を増やすことはしない。

## 表示確認時の注意

園田7Rの保存済み予想には、過去バージョンで保存された「見送り」および参考フォーメーションが表示された。保存済みデータは履歴・精算の整合性を保つため書き換えない。最新の予想オッズモードで通常買い目を確認するには、画面の「最新データで再予想する」から新規予想を生成する必要がある。

再予想では、既にDBへ取り込まれた出馬表を優先し、馬番・馬名・騎手・枠番等の保存済み情報だけで能力スコアを再計算するよう変更した。DBの過去市場オッズ・人気は入力にも公開レスポンスにも使わない。保存済み出馬表がない場合だけ既存の取得経路へフォールバックする。

## 自動検証

`npx tsc --noEmit` とVitest全103件を実行し、通過を確認した。中央・地方の買い目生成テストには、公式EVが未算出でも予想オッズモードでは通常フォーメーションを返すケースを追加した。

## 実画面での再予想確認

園田7Rで「最新データで再予想する」を実行し、保存済み出馬表だけを使った新規予想の表示を確認した。能力スコア58点・推定勝率15.2%の上位2頭には予想オッズ6.6倍が表示され、EVは「未算出」となった。通常のスコア順買い目は3連単9点、3連複3点、合計12点で表示され、公式組合せオッズによるトリガミ判定は保留として表示された。

同画面で既存の穴狙い詳細分析が過去の市場オッズを表示していることを確認したため、公開・予想オッズモードでは当該分析の市場オッズ表示を抑止する。

同じ画面で、保存済みの市場オッズ・人気を出馬表から除外し、穴候補には能力スコアだけを表示することを確認した。市場オッズ由来の候補区分、倍率、人気、穴馬買い目、理由文も公開モードでは表示しない。

通常予想で表示する穴馬軸買い目は、能力スコアから導いた予想オッズを候補選定の基準として継続表示する方式へ統一した。園田7Rの再予想では、穴軸2番の3連単16点、3連複3点、合計19点が表示された。これは公式市場オッズではなく予想オッズに基づく推定であり、EV・市場シグナル・トリガミ判定は未算出として扱う。
