# NAR公式結果データの利用許諾に関する問い合わせ文面

**件名:** レース結果・払戻情報の結果精算・統計評価での利用範囲について

地方競馬全国協会 ご担当者様

お世話になっております。梅林と申します。

地方競馬の予想記録を、レース後に検証する個人運営のWebアプリを開発しています。地方競馬情報サイトに掲載されるレース結果・払戻情報について、利用許諾の範囲を確認したくご連絡しました。

現状、予想時点の買い目を「スコア順」と「穴馬軸」の2戦略に分けて保存しています。レース終了後に、正規に取得した着順上位3頭および払戻情報を使って、各戦略の的中可否・投資額・払戻額を精算し、予想精度の内部評価を行いたいと考えています。

つきましては、次の点をご教示ください。

1. 地方競馬情報サイトのレース結果・払戻情報を、正規のCSV・API・その他の契約データとして取得し、当該アプリのデータベースに保存することは可能でしょうか。
2. 保存したデータを用いて、戦略別の的中率・回収率を算出することは可能でしょうか。
3. 利用可能な場合、個人運営のWebアプリ上で、集計値のみを表示することは可能でしょうか。個別レースの出走表・オッズ・払戻表の転載は想定していません。
4. 利用にあたり必要な契約、申請窓口、データ提供サービス、表示上の条件があればご案内ください。

許諾をいただくまでは、貴サイトのHTML等を自動取得・保存・転載することは行いません。また、回答いただいた利用範囲を超える運用は行いません。

お忙しいところ恐れ入りますが、ご確認のほどよろしくお願いいたします。

梅林
