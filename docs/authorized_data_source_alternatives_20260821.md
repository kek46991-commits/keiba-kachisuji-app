# 正規データ提供候補の調査記録

## 調査目的

NARとの直接契約に依存せず、結果・払戻・オッズを正規に取得し、許諾範囲内で自動取込できる候補を確認する。

## 確認結果

| 候補 | 確認できた事項 | 公開Webアプリへの利用判断 |
|---|---|---|
| JRA-VAN Data Lab. / JV-Link | JRA-VAN公式は、Data Lab.をPC向けサービスとして案内し、JV-Link API、公式データ、リアルタイム・時系列オッズ、対応ソフトの開発者コミュニティを提供している。 | 個人Data Lab.契約データは個人PC内分析に限定する。公開Webアプリへ保存・表示するには、別途商用利用・再配布の許諾を確認する。 |
| HorseRacing DataBase API | 検索結果では、出馬表・払戻金・レース結果のAPIを掲げる外部サービスを確認した。 | 提供範囲、NAR対応、商用利用、再配布、料金、契約条件を提供元へ書面で確認するまで接続しない。 |
| Glad Cube / DRAGON DATA CENTER | 2026年1月29日の公式発表では、地方競馬（ばんえいを除く）の出馬表・リアルタイムオッズ・確定後の結果・払戻をSports NaviへAPI提供している。DRAGON DATA CENTERはB2B向けのデータ活用、API・ウィジェット出力、導入相談フォームを案内している。 | NARデータを別事業者へ再提供できるとは発表だけでは断定できない。B2B相談窓口へ、対象データ・DB保存・戦略別集計・公開範囲の許諾、価格、API仕様を確認する有力候補とする。 |
| 一般的な海外競馬API | 検索結果の公開情報は主に英国・米国・豪州などを対象としており、日本のNAR全レースの提供を確認できない。 | NARの代替には採用しない。 |

## 重要な制約

JRA-VAN Data Lab.の公式製品ページは、Windows PC向けのサービスであること、公式データ・リアルタイムオッズ・TARGET/JV-Linkを提供することを案内している。ただし、同ページだけでは公開Webアプリへの再配布・DB保存・派生集計の許諾範囲は確定しない。個人利用データは、公開Webアプリの取込元に登録しない。

## 次の確認事項

1. 候補提供元に対して、NARの結果・払戻・オッズを提供するか確認する。
2. CSV/APIの自動取得、DB保存、戦略別精算、集計値の公開表示を許可するか確認する。
3. 契約期間、費用、レート制限、保存期間、出典表示、再配布禁止の条件を確認する。
4. 書面の許諾と仕様書を受け取った場合のみ、`authorized_data_sources` に提供元を登録する。

## 追加調査メモ（2026-08-22）

| 候補 | 公開情報で再確認した事項 | 契約準備への反映 |
|---|---|---|
| JRA-VAN Data Lab. / JV-Link | 開発者コミュニティに「競馬データの商用利用のお問い合わせ」の案内がある。 | 個人Data Lab.の転用ではなく、商用利用・公開範囲を同窓口で確認する。 |
| Team-Nave HRDB-API / KeiBa-ODDS-API | 製品案内は、個人利用とビジネス・営利目的の利用を区分し、後者は別途相談・契約としている。HRDB-APIはJRA公式発表情報を対象とし、出馬表・払戻・レース結果を扱う。公開されている個人向け制限は、1ライセンス・1端末、同時3要求、日次6:00〜8:00の定期保守などである。KeiBa-ODDS-APIは中央競馬リアルタイムオッズ向けとして案内されている。 | 個人向けプランを公開Webサービスの取込元に使わない。JRAの結果・払戻・オッズについて、DB保存、戦略別精算、集計公開、サーバー接続、更新頻度を含むビジネスプランの許諾を文書で確認する。NARの対象可否は前提にしない。 |
| NARデータ | 公開検索では、第三者の正式再提供可否を判断できる契約条件までは確認できない。 | NAR直契約または、NAR由来データの公開利用を明示的に許諾できるB2B提供元の書面回答を必須とする。 |

この調査は、公開情報だけでは公開サイト利用許諾を確定できないことを再確認したものである。実データの受領・接続・公開は、対象競技、データ種別、保存期間、公開範囲を含む書面または契約の確認後に限る。
