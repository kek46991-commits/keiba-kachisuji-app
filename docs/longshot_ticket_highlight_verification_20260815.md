# 穴馬軸買い目強調デザインの検証記録

## 実装内容

中央・地方の予想画面で、穴馬軸買い目を専用の星形アイコン、ローズ・パープル・ゴールドの高コントラスト背景、及び「予想オッズ基準」バッジで強調した。保存済み予想の2系統カードにも同じ視覚階層を適用した。

強調カード内には「公式オッズではなく、能力スコアから導いた予想オッズによる推定」である注意文を残し、公式市場オッズ・EV・トリガミ判定と混同しないようにした。

## 自動検証

型検査とVitest全106件は通過した。

## 画面検証

園田7Rの地方予想URLをデスクトップ（1280px）とモバイル（375px）で確認した。両方のキャプチャ時点ではレース情報の読み込み中表示が継続し、強調カードまで到達しなかった。既存の非同期データ取得を確認してから、表示済み状態でカードのコントラストとモバイルの折返しを再確認する。

その後、地方予想のURLビューでエラー状態をローディングと区別する表示へ改善し、再確認を行った。園田7Rでは、デスクトップ・モバイルの両方で穴馬軸カードがスコア順カードより明確なローズ・パープルの背景とゴールドの推定バッジで表示された。モバイル幅でも「穴馬軸」「予想オッズ基準」「推定」のラベル、3連単・3連複の内容、公式オッズではない旨の注意文が折り返し崩れなく確認できた。

中央予想の中京7Rは、出走馬データ取得とスコアリングの完了を待って再確認した。穴馬軸カードはローズ・パープルの背景、星形アイコン、ゴールドの「予想オッズ基準」バッジとともに表示され、3連単16点・3連複3点・合計19点の構成、公式市場オッズではない旨、EV・トリガミ判定が未算出である旨を確認できた。初回の読み込み中表示は、予想生成リクエストの完了待ちであり、完了後は通常表示へ遷移した。
