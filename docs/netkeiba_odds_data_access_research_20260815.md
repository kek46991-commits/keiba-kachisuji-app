# オッズデータの利用経路に関する調査記録

調査日: 2026-08-15

## 結論

本サービスのサーバーがNetkeibaの画面や通信を自動取得して、オッズをDBへ保存・アプリ利用者へ表示する経路は採用しない。Netkeibaの利用規約は、同社が承認した場合を除き、サービスを通じて得たデータを私的利用の範囲を超えて複製・販売・出版することを禁じ、不特定または多数者が知り得る状態に置くことも私的利用を超えるとしている。営利目的の利用も、別途承認が必要である。[1]

> Netkeibaの情報を自動取得したり、本アプリへ取り込んで再表示したりする方法は、**書面等による明示的な利用許諾が得られるまで実装しない**。画面のスクリーンショットをOCRしてデータ化する経路も同様に採用しない。

## 確認済みの公式情報

| 提供元 | 確認事項 | 本プロジェクトへの扱い |
| --- | --- | --- |
| Netkeiba | 同社の承認なしに、サービスから得たデータを私的利用の範囲を超えて複製・公開することは不可。営利利用も別途承認が必要。[1] | 画面スクレイピング、通信の模倣、抽出データのサーバー保存・再配信は実装しない。必要なら運営会社へ書面で利用許諾を問い合わせる。 |
| JRA公式サイト | Web上で最新オッズとレース終了後の最終オッズを閲覧できる。[2] | 閲覧用の一次情報として案内するが、サーバーによる自動取得・再配信には利用しない。 |
| JRA-VAN Data Lab. | Windows PC向けで、リアルタイムオッズを含む。[3] 通常契約によるエンドユーザーへのデータ配信・商用利用は不可。[4] | 個人利用のData Lab.からは、利用者自身が正規の対応ソフトで出力したCSV/JSONを本アプリへ手動取込する場合のみ検討する。 |
| JRADB | JRAが提供する商業利用契約。法人契約が必要。[4] | 将来、法人化し明示的な契約を取得できた場合のみ、サーバー側の自動連携候補とする。 |

## 推奨する現行フロー

1. Netkeibaのデータ利用が必要な場合は、運営会社に「対象データ（単勝・複勝・組合せオッズ）、取得頻度、保存期間、画面表示対象者、営利性、技術方式」を提示し、書面等で許諾範囲を確認する。
2. 許諾を得られない間は、ユーザーが正規に閲覧・取得でき、アプリへの取込・再利用を許された公式または許諾済みのオッズCSV/JSONを用意する。
3. 本アプリの「公式オッズ取込」画面から手動アップロードする。
4. 取込元、取得時刻、対象レース、主催者を監査履歴へ保存する。
5. 単勝・複勝・組合せオッズの不足は「未取得」と表示し、推測値で補わない。
