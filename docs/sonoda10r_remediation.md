# 園田10R事象に基づく予想改善仕様

## 検証優先プロンプト

> 予想と買い目を生成する前に、`raceId`、開催日、競馬場、レース番号、レース名、芝・ダート、距離、馬場状態を正規レースレコードと照合する。距離、競馬場、コースが入力値と異なる場合は、正規レコードの値を採用し、補正内容を返却する。日付・競馬場・レース番号の三条件で正規レコードが特定できない場合は、推測で予想を生成しない。

> 穴馬分析で上位5頭に選ばれた馬は、三連単の2・3着候補、三連複の保険BOX、人気馬とのワイド相手に必ず含める。本命馬だけに依存した買い目を作らず、穴馬TOP5の組込み状況を買い目文字列と根拠に明記する。

## 実装上のガードレール

| 項目 | 変更内容 | 効果 |
|---|---|---|
| レース照合 | `raceId`に加え、開催日・競馬場・R番の三条件を全一致で検証 | 近接Rへ誤結合するフォールバックを防止 |
| 条件採用 | 正規レコードの距離・芝ダ・馬場をスコアリングへ強制適用 | 1700mと1400mのような前提崩れを防止 |
| 条件表示 | 補正後の正規条件と不整合警告を予想画面へ返却 | 利用者が計算前提を確認できる |
| 穴馬買い目 | 穴馬候補をTOP3で切らずTOP5まで維持 | 4・5位候補が推奨買い目から消えない |
| リスクヘッジ | 穴馬TOP5の三連複BOXを保険として併記 | 本命馬が不発の場合の組み合わせを残す |

## 対象事象の注意

ユーザー報告の着順・払戻に該当する正確な開催日はDBと公開確認結果からは確定できなかった。したがって、今回の修正は特定結果を後追いで最適化するものではなく、異なるレース条件で計算してしまう構造的な不具合と、穴馬TOP5を買い目から切る構造を解消するものである。
