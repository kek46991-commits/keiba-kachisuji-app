# TARGET frontier JVを使う個人オッズ分析の手順

## 利用範囲

この手順は、JRA-VAN Data Lab.とTARGET frontier JVを契約者本人がPC上で使う**個人分析**に限定する。TARGETから取得・表示した公式オッズ、時系列オッズ、CSVは、公開中の「競馬でGO！」へアップロード、保存、転載、グラフ化しない。公開サイト側では従来どおり、能力スコアから導いた予想オッズを「予想オッズ」と明示して表示する。

## 当日オッズを確認する手順

1. PCでTARGET frontier JVを起動し、対象の開催日・競馬場・レースを選択する。
2. 出馬表またはオッズ画面を開く。Data Lab.の速報オッズが未取得の場合は、オッズ画面の**「JV速報データのダウンロード」**または**「JVオッズ取得」**を実行する。[1]
3. 単勝・複勝・馬連などは通常のオッズ画面で確認する。時系列を確認したい場合は時系列オッズ画面を開き、**「JVオッズ取得」**で当該データを取得する。[1] [2]
4. 時系列オッズバーから特定時刻の状態を選び、オッズ変動を個人分析に使う。Data Lab.の公式案内では、単勝・複勝・枠連・馬連の時系列オッズに対応し、当日の変動や異常オッズの確認に使えるとしている。[2]
5. CSV出力が必要でも、PC内での個人分析・記録にとどめる。対象画面ではF8のファイル出力から複数のCSV形式を選択できるが、公開サイトのデータ源にはしない。[1]

## 予想オッズとの使い分け

| 確認場所 | 表示する値 | 目的 | 公開サイトへの使用 |
|---|---|---|---|
| TARGET frontier JV | Data Lab.の公式オッズ・時系列オッズ | 契約者本人の個人分析 | 使用しない |
| 競馬でGO！ | 能力スコアから導く予想オッズ | 公開予想の比較・買い目構成 | 使用する |

TARGETの画面上の「推定票数」やシェアはオッズ等からの逆算値であり、公式票数そのものではなく誤差を含む場合がある。個人分析でも確定的な指標として扱わない。[1]

## 公開サイト側の分離確認

公開許諾済みオッズ取込画面は、公開表示・保存・派生計算を提供元との契約で許可されたファイルだけに限定した。TARGET/Data Lab.の個人分析CSVは、画面上で明示的に取込不可と案内し、サーバー側でもファイル名およびTARGET標準出力に含まれる時刻列の署名を検出して取込を拒否する。一般形式の許諾済み提供元CSVは別途の契約確認を前提に検証可能である。

管理画面で、個人分析用CSVの除外案内、公開許諾済みファイルの限定、及びスマホでのファイル選択導線が表示されることを確認した。サーバーの拒否ロジックは、TARGET名を含むファイル名、またはTARGET標準の時刻出力列を持つ内容を拒否するテストを含めて検証済みである。
