# JRA-VANスマホアプリ由来オッズの取込可否

## 結論

JRA-VANスマホアプリから当サイトへオッズを自動取得・保存する経路は採用しない。JRA-VAN利用規約は、Androidアプリについてアプリ以外からのアプリ用サーバー接続、およびアプリで取得したデータの他プログラム利用を禁止している。[1]

JRAの公式サイトは最新オッズの閲覧を案内しているが、公式CSV/JSONのダウンロードAPIは確認できなかった。[2] JRA-VAN Data Lab.ではリアルタイム・時系列オッズを提供するが、Windows PC向けのJV-Linkを前提とする。[3] また、Data Lab.の通常契約だけで、利用者向けWebアプリへデータを配信することはできず、商用のエンドユーザー配信には法人向けJRADB契約が必要と案内されている。[4]

JRA-VANのTARGET frontier JVにはオッズCSV出力仕様があるが、これはData Lab.対応のPCソフトからの出力であり、スマホアプリのデータを持ち出す経路ではない。[5] そのため、スマホのみ・現行個人契約という条件では、利用許諾の明記された第三者CSV/JSON提供元を利用者が別途契約するか、法人化後にJRADB契約へ進むまで、実オッズの自動取込は保留とする。

## サイト側の準備状況

競馬でGO！には、許諾済みCSV/JSONを検証して保存する公式オッズ取込画面とAPIが既にある。取り込み前に、提供元の利用規約でWebアプリへの保存・表示が許可されていることを確認する。アプリ画面の画像、画面から読み取った数値、ID・パスワード、アプリ通信は入力元として使用しない。

TARGET frontier JVの標準オッズCSVは「レースID」「馬番」「馬名」「単勝オッズ」「複勝オッズ下限」「複勝オッズ上限」を含むため、既存パーサーで取り込めることをユニットテストで確認した。CSVには追加列が存在しても、必要列だけを検証して単勝・複勝オッズを保存する。取込画面には、TARGETからのCSV出力手順と対応列を表示する案内を追加した。[5]

## 公開ホームページへの反映方針

TARGET frontier JVおよびData Lab.の通常契約は、個人利用での分析を前提とするため、公開ホームページのオッズ表示・再配信の入力元には使用しない。公開配信が可能な契約が有効になるまでは、予想画面でオッズ、EV、オッズに依存するトリガミ判定を「公式オッズ未取得」として扱う。能力スコアはオッズと独立して表示するが、オッズやEVを推測値で代替しない。

公開ページへオッズを提供する連携は、JRA-VANが案内する法人向けのJRADB等で、対象データ、APIまたはファイル提供方式、表示・二次利用・保存期間の条件を書面で確認してから実装する。[4]

JRA-VANの2026年7月の公式案内では、エンドユーザーへのデータ配信を伴うアプリ・サービスはData Lab.の通常契約では利用できず、JRAが提供する商業利用契約「JRADB」が必要とされている。JRADBは法人契約のみで、申込みには法人名と法人確認書類またはコーポレートメールアドレス等が必要である。サービス詳細・料金・利用条件の照会窓口は、JRA-VANサポートデスク（office@jra-van.jp、公式案内の受付時間内）である。[6]

法人化後は、同窓口へ「公開サイトでの中央競馬オッズ表示・履歴保存・EV算出を予定している」ことを伝え、単勝・複勝・組合せオッズの提供可否、更新頻度、API/ファイル形式、許可される表示範囲、保存期間、料金、審査要件を文書で確認する。その条件が得られるまでは、TARGET CSVを公開用途に取り込まない。

## 会員ページ・Data Lab.開発者コミュニティの再確認

ユーザー提示の会員ページはJRA-VAN IDによる会員ログイン画面であり、個人会員向けに公開Webサイトのオッズ配信を許可する別契約は確認できなかった。Data Lab.の公開製品案内は、リアルタイムオッズ、TARGET、JV-Link APIをデータラボ会員向けPCソフト・開発用途として案内している。[11]

一方、Data Lab.開発者コミュニティの公式アナウンスは、JV-Linkデータを使ってエンドユーザーにデータを提供するスマホアプリや商用利用は、再配布（二次利用）に当たり通常契約だけでは不可と明記している。公開サイトへオッズを保存・表示する今回の目的はこの制約に該当するため、会員ページへログインしても公開連携の許諾は得られない。個人・法人化前の公開用途では、提供元から書面許諾が得られる別サービスを使うか、法人化後にJRADBを検討する必要がある。[12]

## 法人化前に可能な公式オッズ導線

JRA公式サイトは、競馬メニューの「オッズ」または各レースの出馬表から最新オッズを閲覧できると案内している。[7] ただし、これは閲覧用の公式ページであり、第三者サイトのデータ取得APIや転載許可を示すものではない。JRAは公式サイト上のコンテンツの二次利用について、私的使用や引用の範囲を超える場合は事前許諾を求め、申請を法人に限定している。[8]

したがって、法人化前の公開サイトで採用できる安全な代替は、当サイトからJRA公式のオッズ閲覧ページへ遷移させる外部リンクである。オッズ値を取得、保存、転載、グラフ化、EV算出へ流用する方式は採用しない。外部データベンダーについても、日本のJRAオッズを対象とし、個人運用での公開・二次利用を契約上明示するものは、現段階で確認できていない。

## 検討候補：KeiBa-ODDS-API

Team-NaveのKeiBa-ODDS-APIは、JRAの単勝・複勝・各種組合せを含むリアルタイムおよび最終オッズをHTTPSで取得するAPIとして案内されている。個人利用料金は月額14,300円（税込）と明記される一方、ビジネス・営利目的では別途相談・契約のうえビジネスプランを利用するよう明記されている。[9] 公開サイトでの表示、保存、再配信、契約主体（個人可否）、許容アクセス数、データ起源の権利関係は公開ページだけでは確定できないため、導入前に書面で確認が必要である。[10]

個人の通常プランは「IPATで馬券を購入する顧客向け」とされ、1ライセンス当たり同時1要求・1端末からのアクセス制限がある。[10] よって、通常プランのキーをサーバーに設定して公開サイトへ配信することは行わない。Team-Naveが公開サイト表示を明示的に許諾するビジネスプランを提示し、JRAオッズの提供権限と対象用途を確認できた場合だけ、個別契約として検討する。
