# 公式結果データ自動取得の接続確認

確認日: 2026-08-13

| 提供元 | 公式資料で確認した事項 | Webアプリへの影響 |
|---|---|---|
| JRA-VAN Data Lab. | Windowsパソコン向けサービスで、利用には利用キー設定とJV-Linkのインストールが案内されている。 | スマホのみ・Linux上のWebアプリから、利用キーだけで直接呼べる公開HTTP APIとしては扱えない。 |
| JV-Link | JRA-VAN Data Lab.を利用するためのインターフェースモジュールとして案内されている。 | 許諾済みのサーバー向け配信APIまたは提供元承認済みの中継サービスがない限り、Webアプリの自動取得先として推測接続しない。 |

## 採用方針

1. 公式CSV/JSONの取込と、その直後の予想精算・成績反映は継続して利用する。
2. 自動取得は、提供元が契約上許可したHTTP API、ファイル配信、または中継APIの仕様・認証情報が提供された場合だけ実装する。
3. 未許諾サイトのスクレイピングや、推測したエンドポイントへのアクセスは行わない。
