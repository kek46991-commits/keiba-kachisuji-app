## 件名

> KeiBa-ODDS-APIの公開競馬予想Webサイトでの利用可否について

## 本文

> 株式会社Team-Nave ご担当者様
>
> お世話になります。競馬予想Webサイト「競馬でGO！」を個人で運営準備しています。中央競馬のオッズを、利用規約に適合する形で公開サイトへ表示できるサービスを検討しており、KeiBa-ODDS-APIのビジネスプランについて確認をお願いしたくご連絡しました。
>
> 現時点では個人運営で、将来的な法人化を予定しています。サイト上では、単勝・複勝・組合せオッズを表示し、時系列として保存すること、ならびにオッズと独自の能力スコアを用いたEV・トリガミ判定を表示することを検討しています。ログインの有無を問わず、一般の閲覧者がページを閲覧できる公開サイトを想定しています。
>
> 以下について、書面または利用規約上の根拠を含めてご教示ください。
>
> 1. 法人化前の個人事業・個人運営でも、ビジネスプランまたは同等プランを契約できますか。
> 2. APIから取得したJRAの単勝・複勝・組合せオッズを、公開Webサイトで表示・キャッシュ保存・履歴グラフ表示できますか。
> 3. 取得オッズを入力として独自計算した期待値、損益分岐、トリガミ判定を公開表示できますか。
> 4. オッズデータの保存期間、再表示・二次利用、スクリーンショット掲載、出典表示に関する条件はありますか。
> 5. 想定する更新頻度（発走前の定期更新）に対するAPI上限、推奨する取得方式、料金、初期費用、最低契約期間を教えてください。
> 6. JRAのみを対象にした場合の提供範囲、組合せオッズの対応券種、レスポンス形式、テスト環境の有無を教えてください。
>
> 上記が明示的に許可される場合にのみ、APIキーを用いた連携を実装します。許可範囲に含まれない場合は、該当データの取得・公開は行いません。
>
> お忙しいところ恐れ入りますが、よろしくお願いいたします。

## 回答後に連携を開始する条件

次の全項目が書面または契約書・利用規約で確認できるまでは、APIキーの登録、オッズ取得、公開表示を開始しない。

| 確認項目 | 必要な回答 |
|---|---|
| 契約主体 | 個人または法人化前の事業者が契約可能であること |
| 公開表示 | 不特定多数が閲覧するWebページへの表示が許可されること |
| 保存・履歴 | DBキャッシュ、履歴グラフ、再表示が許可されること |
| 派生計算 | EV・損益分岐・トリガミ判定などの独自計算表示が許可されること |
| データ範囲 | 単勝・複勝・組合せオッズと、必要な券種が利用可能であること |
| 運用条件 | レート制限、更新頻度、出典表記、料金、契約期間が明確であること |
